# Как измерять эффект

Сравнивать задачи сопоставимого объёма. Отдельно записывать время участия человека и полное время выполнения, включая ожидание.

| Показатель | Что записывать |
| --- | --- |
| Объём | Тип страницы, блоки, готовность материалов |
| Время человека | Постановка, объяснения, проверка, исправления |
| Полное время | Начало и завершение задачи |
| Повторные объяснения | Повторы правил, уже записанных в общей базе |
| Циклы правок | Возвраты после проверки |
| Качество | Отклонения от общих правил при первой приёмке |
| Повторное использование | Согласованные блоки и время подключения |
| Распространение изменений | Обновлённые и ожидающие страницы-потребители |

Первую страницу использовать как точку отсчёта. Следующие сравнивать с поправкой на объём и готовность материалов. Одного примера недостаточно, чтобы обещать кратное ускорение.

## Текущий результат

Измерения сквозного пилота ещё не собраны. Подтверждена организационная основа: отдельные рабочие чаты, брендбук, целевая карта и общие файлы контекста. Следующее обновление должно добавить заполненную карточку реальной задачи и доказательства результата.
